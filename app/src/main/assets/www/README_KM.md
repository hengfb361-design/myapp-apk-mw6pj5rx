# Pool Floating Tools (Android)

នេះជា APK project គំរូសម្រាប់ Floating Overlay លើអេក្រង់ Android ដែលបានបន្ថែមមុខងារ **Extended Line Canvas (ខ្សែវែងៗ)** សម្រាប់ជំនួយការតម្រង់គ្រាប់បាល់ក្នុង practice mode។

## Features (មុខងារ)
- **Floating POOL Button:** អាចអូស និងបិទ/បើក Menu បានលើអេក្រង់។
- **Extended Aim Line Canvas:** គូសបន្ទាត់តម្រង់វែង (Main Aim Line) ព្រមទាំងបន្ទាត់ប៉ះបញ្ចាំង (Target Trajectory Line) លើអេក្រង់ហ្គេម។

## Build Instruction
1. បើក project នេះក្នុង Android Studio ឬ IDE (ដូចជា Termux / Cosmic IDE)។
2. ប្រើ JDK 17 និង Android SDK Platform 35។
3. Sync Gradle ហើយ Build > Build APK(s)។
4. ដំឡើង APK លើទូរស័ព្ទ Android រួចផ្តល់សិទ្ធិ `Display over other apps` (SYSTEM_ALERT_WINDOW)។
